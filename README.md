# LPOS Arifin

A React + Vite + Tailwind CSS project setup.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Project Structure

- `src/` - Source code
- `public/` - Static assets
- `dist/` - Production build output

## Technologies

- **React** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Utility-first CSS framework
- **Firebase** - Backend services
- **Lucide React** - Icon library
